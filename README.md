# 황성준 변호사 채널 콘텐츠 워크벤치

PDF 인수인계서의 운영 흐름을 바탕으로 만든 정적 웹앱입니다.

## 주요 기능

- 운영 홈 기반 다음 액션 안내
- 버튼 기반 자동 웹 수집
- 뉴스, 블로그·웹, 커뮤니티, 판례·법률 검색 결과 수집
- 후보 선별 전용 큐와 단계별 필터
- RSS/원문 보조 등록
- 키워드 기반 카테고리 태깅
- 소재 후보 점수화
- 변호사님 원석 입력
- RSS 소재와 원석 결합
- 황성준 변호사 채널 문법의 제목, 훅, 썸네일 문구 생성
- 검수 상태 관리
- 법률·광고 리스크 가드레일
- CSV/JSON 내보내기

## 실행

브라우저에서 `index.html`을 열면 바로 실행됩니다.

데이터는 브라우저 `localStorage`에 저장됩니다.
